# Interests Index

Every page under `~/memory/interests/` — one accumulating file per interest
of the user's, built from dated evidence. A page is created only with real
evidence (repeated time/attention, or a clearly stated interest), never
from a single passing mention. See the skill's `references/layout.md`.
